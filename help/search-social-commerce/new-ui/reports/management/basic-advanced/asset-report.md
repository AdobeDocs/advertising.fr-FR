# [!UICONTROL Asset Report]

*Applicable aux campagnes activées pour [!DNL AI Max] dans les comptes [!DNL Google Ads] uniquement*

Le [!UICONTROL Asset Report] inclut les données de conversion au niveau de la ressource pour le coût, les clics et (facultativement) les [!DNL Google] suivies par l’IA pour chaque ressource générée par l’IA applicable dans les campagnes activées par [!DNL AI Max]. Le rapport n’inclut pas les conversions Adobe Analytics. Utilisez ce rapport pour déterminer la priorité des ressources à conserver, mettre en pause ou remplacer.<!-- Not included as of 7/22/26: You can optionally include advertiser-specific label classifications. -->

Par défaut, les données incluent une ligne pour chaque ressource applicable (telle qu’un logo, une image, une vidéo ou un titre) avec au moins une mesure suivie pour chaque unité de temps dans la période spécifiée. Par défaut, les lignes sont classées par ordre croissant selon le nom de la campagne.

Les données de [!DNL Google Ads] sont généralement disponibles pour les 36 mois précédents.
