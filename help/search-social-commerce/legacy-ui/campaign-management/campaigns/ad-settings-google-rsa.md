# [!DNL Google Ads] paramètres des annonces responsive sur le Réseau de Recherche

[!DNL Google Ads] assemble dynamiquement [des annonces de recherches réactives](https://support.google.com/google-ads/answer/7684791?hl=en) (RSA) avec jusqu’à trois titres et deux descriptions.

>[!NOTE]
>
>Chaque groupe d’annonces peut inclure jusqu’à trois annonces responsive sur le Réseau de Recherche activées.

Voir l’aide de [!DNL Google Ads] pour les [limites publicitaires par compte](https://support.google.com/google-ads/answer/6372658?hl=en).
