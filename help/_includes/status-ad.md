# Champ Statut dans les paramètres publicitaires

**[!UICONTROL Status]:** statut d’affichage de l’annonce publicitaire : *Actif* (pour activer les enchères, valeur par défaut), *En pause* (pour désactiver les enchères) ou *Supprimé* (pour supprimer l’annonce publicitaire, annonces existantes uniquement).
