# Texte et modèle - Niveau de stock

**[!UICONTROL Stock Level]:** (facultatif) colonne numérique ou textuelle dans le fichier spécifié qui représente le niveau de stock d’un produit ou d’un service. Le nom de la colonne est remplacé par les données réelles lorsque le fichier de flux spécifié est propagé dans le modèle. Pour insérer une valeur, cliquez dans le champ de saisie, puis cliquez sur le nom de la colonne dans la liste des colonnes.

Vous pouvez décider de suspendre ou de supprimer les publicités de votre inventaire pour les articles en rupture de stock à l’aide du paramètre [données de flux](/help/search-social-commerce/legacy-ui/campaign-management/inventory-feeds/feed-settings-manage.md#feed-data-settings) « [!UICONTROL When a numeric stock level reaches N units, or where a text-based value is 'out of stock.'] »
