# Champ de filtre d’inventaire dans les paramètres des campagnes d’achats GGL et MS

**[!UICONTROL Inventory Filter]:** (Campagnes d’achat uniquement ; facultatif) produits avec des attributs spécifiques à annoncer pour la campagne. Si vous ne spécifiez pas de filtres d’inventaire, le réseau publicitaire peut faire la publicité de n’importe quel produit de votre magasin.

Vous pouvez saisir jusqu’à sept combinaisons dimension-attribut de produit sur lesquelles filtrer vos produits, à l’aide du format `dimension=attribute`. Séparer plusieurs filtres
avec un délimiteur « `>>` ». Pour obtenir une liste des dimensions de produit disponibles, voir « [Filtres de produit de campagne d’achat](/help/search-social-commerce/legacy-ui/campaign-management/campaigns/shopping-campaign-product-filters.md) ».

L’exemple suivant montre des annonces pour des fournitures Acme pour animaux de compagnie :

`CategoryL1=animals>>CategoryL2=pet supplies>>Brand=Acme Pet Supplies`
