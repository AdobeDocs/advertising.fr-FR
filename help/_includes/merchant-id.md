# Champ d’ID de commerçant dans les paramètres de campagne d’achats GGL et MS dans la grille et dans les modèles ACM

**[!UICONTROL Merchant ID]:** (campagnes d’achat et campagnes d’audience liées à un flux de commerçant uniquement) ID client du compte commerçant dont les produits sont utilisés pour la campagne.

Pour [!DNL Microsoft Advertising] campagnes d’audience liées à un magasin de centre commercial, sélectionnez le [!UICONTROL Merchant ID] dans la liste de tous les magasins liés au compte de recherche. Une fois que vous avez lié la campagne à un magasin et enregistré les paramètres, vous ne pouvez plus modifier cette option.
