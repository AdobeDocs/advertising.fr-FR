# Texte et modèle - Modificateurs

**[!UICONTROL Modifiers]:** Une liste de tous les [groupes de modificateurs](/help/search-social-commerce/legacy-ui/campaign-management/inventory-feeds/modifiers-manage.md) pour l’annonceur. Pour afficher les valeurs de modificateur associées à un groupe de modificateurs, cliquez sur le nom du groupe ; les valeurs s&#39;affichent dans le panneau gris au-dessous.

Lorsque vous insérez un groupe de conditions commerciales dans un champ de modèle, la valeur insérée est indiquée sous la forme `<modifier_group_name>`, où « modificateur_group_name » est le nom du groupe de conditions commerciales spécifié, pour indiquer que la valeur est une variable.

Chaque modèle ne peut utiliser qu&#39;un seul groupe de conditions commerciales.
