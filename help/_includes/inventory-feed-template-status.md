# Texte et modèle - Statut

**[!UICONTROL Status]:** statut du modèle : *[!UICONTROL Active]*, *[!UICONTROL Paused]* ou *[!UICONTROL Deleted]*.

Les données de flux ne peuvent être automatiquement propagées que par le biais de modèles actifs. Cependant, vous pouvez propager manuellement les données par le biais d’un modèle en pause.
