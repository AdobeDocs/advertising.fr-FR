# Paragraphe utilisé dans l’introduction de certains fichiers d’annexe de feuilles d’envoi groupé

Chaque feuille d&#39;envoi groupé doit inclure les champs d&#39;en-tête et les champs de données correspondants requis pour les [opérations spécifiques que vous souhaitez effectuer](/help/search-social-commerce/set-up/bulksheets/bulksheet-data-formats/bulksheet-operations.md) (telles que la création d&#39;une publicité). Lorsqu’un champ n’est pas obligatoire, vous pouvez l’omettre dans l’en-tête et les lignes de données. Toutes les colonnes personnalisées sont supprimées lorsque vous téléchargez le fichier de feuille d’envoi groupé.

Vous trouverez ci-dessous les champs d’en-tête disponibles et les descriptions des champs de données correspondants, ainsi que des informations supplémentaires sur ceux qui sont nécessaires pour ajouter, modifier ou supprimer des données.
